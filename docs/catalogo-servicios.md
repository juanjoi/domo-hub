# Catálogo de servicios

Servicios definidos en este repositorio. Cada servicio se añade como una fila más al migrarlo o darlo de alta.

| Servicio | Categoría | Propósito |
| --- | --- | --- |
| Traefik | Infraestructura | Proxy inverso: recibe las peticiones web y las reparte según el nombre |
| domo-board | Infraestructura | Panel para actualizar los stacks con un botón |
| domo-menu | Infraestructura | Menú común: botón en el borde de cada aplicación web que abre la lista de aplicaciones |
| File Browser | Familia | Acceso web a los ficheros compartidos |
| Jellyfin | Familia | Películas y series |
| Mosquitto (MQTT) | Domótica | Bus de mensajes entre Zigbee2MQTT y Home Assistant |
| Zigbee2MQTT | Domótica | Puente entre los dispositivos Zigbee y MQTT |
| Home Assistant | Domótica | Control de la casa ([puesta en marcha](homeassistant.md)) |
| Asistente de voz | Domótica | Whisper (voz a texto) y Piper (texto a voz) para Assist ([puesta en marcha](asistente-voz.md)) |

Categorías: **Infraestructura**, **Familia**, **Domótica**.
